# ES6 Basics

Bu layihə ES6 (ECMAScript 2015) əsaslarını öyrənmək üçün hazırlanmışdır. Layihədə aşağıdakı mövzular əhatə olunur:

## Tapşırıqlar

### 0. Const və let
- `const` və `let` açar sözlərinin istifadəsi
- `var` əvəzinə müasir dəyişən təyin etmə üsullarının tətbiqi

### 1. Blok səviyyəli dəyişənlər
- Blok səviyyəli əhatə dairəsi
- `let` və `const` ilə blok səviyyəli dəyişənlər

### 2. Arrow funksiyaları
- Ənənəvi funksiyaların arrow funksiyalarına çevrilməsi
- `this` kontekstinin idarə edilməsi

## Quraşdırma

1. Node.js və npm quraşdırın
2. Layihə qovluğunda `npm install` əmrini işlədin
3. Tapşırıqları test etmək üçün `npm test` əmrindən istifadə edin

## İstifadə

Hər bir tapşırıq üçün ayrıca JavaScript faylı mövcuddur. Faylları ayrıca test etmək üçün:

```bash
npm run dev 0-main.js
